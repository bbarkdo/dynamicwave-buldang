# 다이나믹웨이브 불당점 홈페이지 (천안 불당동 키즈 & 성인 프라이빗 수영장)

정적 사이트입니다. `index.html`을 브라우저로 열면 바로 확인할 수 있습니다.
**일상적인 수정은 `data.js` 한 파일만** 고치면 됩니다. (`★` 표시 = 아직 임시값)

로고 이미지: `assets/logo-mark.png`(원형 마크), `assets/logo.png`(글자 포함).

## 시간표 · 여석 바꾸기 (`classes`)
한 줄이 한 수업 칸입니다. **회원 이름은 절대 넣지 말고 인원 숫자만** 적어주세요.
```js
['월', '16:00', 1, '5세', '초급', 2],
// 요일, 시간, 수조(1=퐁당풀/1호실, 2=첨벙풀/2호실), 반('5세' | '유아' | '초등' | '신규'), 단계, 현재 인원
```
- 정원은 `cap`에서 자동 적용 (5세 3명, 유아·초등 4명). 특정 반만 다르면 7번째 칸에 정원 숫자 추가.
- **대기 인원**은 7번째 칸에 숫자로 적어요. 예: `['토', '09:00', 1, '유아', '', 4, 4]` → 마감 · 대기 4명
  - 대기자는 남은 자리를 먼저 채운 것으로 계산해요 (예: 정원 4, 3명 + 대기 1명 → 마감)
  - 대기 1~2명은 회색, 3명 이상은 빨간색으로 표시돼요. 숨기려면 `showWait: false`
- 1자리 남음 → **임박**(주황), 정원 = 인원 → **마감**(빗금 + 빨간 도장, 대기 접수)
- 아직 개설 안 된 시간은 반을 `'신규'`로 적으면 흐린 점선 빈칸 "수업 없음 · ＋ 개설 가능 · 2인부터"로 표시됩니다 (5세 · 유아 · 초등 모두 개설 가능)(`newMin`). 반이 열리면 `'유아'`나 `'초등'`으로 바꾸고 인원을 적어주세요.
- 수조 이름(퐁당풀 · 첨벙풀)은 `rooms`에서 바꿀 수 있어요. 성인 레슨 시간은 `info.adultHours`.
- 반을 새로 열면 줄을 복사해 추가, 없어지면 줄 삭제.
- 수정 후 맨 위 `updated` 날짜도 바꿔주세요. 시간표 위에 "○월 ○일 기준 여석"으로 표시됩니다.
- 개인 · 듀엣 레슨은 시간표에 표시하지 않고, "정규반 외 시간 협의"로 안내합니다.

## 성인 · 개인레슨 시간표 (`privateHours`, `privateBooked`)
- 시간표의 "🙋 성인 · 개인레슨" 탭은 평일 오전 · 평일 저녁 · 토요일 카드로 보여줘요. 카드마다 예약이 찬 시간만 표시하고, 찬 비율로 "예약 가능 · 인기 시간대 · 마감 임박"이 자동으로 붙어요.
- 개인 · 듀엣 · 트리오 레슨이 새로 잡히면 `privateBooked`의 해당 수조에 `'요일 시'`를 추가해요. 예: `'화 20'`
  - 레슨이 끝나면 그 줄을 지우면 다시 '가능'으로 바뀌어요. 정규반 수업 시간은 자동으로 막혀요.

## 자유수영 · 대관
- 상담 신청에 "🏊 자유수영" 탭(네이버 예약 버튼, 초등 이하 성인 동반 필수 안내)과 "🎉 대관" 탭(별도 협의용 문의 문자)이 있어요.
- 네이버 예약 주소는 `data.js`의 `info.naverBooking`에 넣어요. 비어 있으면 네이버 지도 검색으로 연결돼요.

## 상담 신청서 희망 시간 (`regularHours`, `privateHours`)
- 희망 프로그램은 하나만 고를 수 있고, 고른 프로그램에 맞는 정각 시간만 나와요.
  - 5세 특별반 · 키즈 정규반 → `regularHours` (평일 14~18시, 토 09~13시)
  - 개인 · 듀엣 · 트리오 · 자유수영 → `privateHours` (평일 06~13시 · 19~21시, 토 09~13시)

## 나이 기준 (상담 신청서 생년월일)
- 만 48개월 이상 = 5세 → 5세 특별반만 신청 가능 · 6~7세 → 유아 정규반 · 초등 → 초등 정규반 (3월 학년 기준)
- 만 48개월 미만: 정규반 버튼이 잠기고 개인 레슨 안내 + 대소변 가리기 · 기저귀 착용 불가 배너 표시 (사전 접수 없음)
- `preFiveMonths` (기본 3): 48개월이 되기 이 개월 수 안쪽이면 배너에 '수영장으로 바로 문의' 문구 추가

## 공개 주소 · 배포
- 공개 주소: https://www.dwave-buldang.kr/ (가비아 도메인 → GitHub Pages, 저장소 `dynamicwave-buldang`)
- 이 폴더(`dynamicwave/`)의 내용이 그 저장소의 맨 위(루트)에 그대로 들어갑니다.
- 도메인을 따로 구입하면 `index.html`의 canonical · og 주소, `robots.txt`, `sitemap.xml`의 주소를 새 도메인으로 바꾸고 저장소에 `CNAME` 파일을 추가합니다.
- 공유 미리보기 이미지: `assets/og-image.jpg` · 개인정보처리방침: `privacy.html`

## 방학특강 창 (`special`)
- `mode: 'soon'` → 일정 · 여석은 숨기고 "11월 초 공개 예정" 안내만 표시 (`soonText`, `soonDesc`)
- 특강을 공개할 때 `mode: 'open'`으로 바꾸고 `period`, `parts`(부별 대상 · 정원)를 채웁니다.
- `from` ~ `to` 기간에만 자동으로 띠 · 섹션 · 팝업이 나타나고, 기간이 지나면 자동으로 사라집니다.
- 당장 숨기려면 `show: false`, 팝업만 끄려면 `popup: false`.
- `parts`에 부(시간)별로 두 수조(`pools`)를 묶어 적어요. 수조마다 `target`(대상), `cap`, `cur`로 여석 표시. 방문자가 "이 시간 신청하기"를 누르면 상담 신청서에 담깁니다.

## 가격 (`prices`, `priceNotes`)
구역마다 `{ title, sub, m3, rows }`. 금액은 숫자로 적으면 쉼표가 자동으로 붙고, `m3: true`인 구역은 '3개월권' 보기에서 ×3×0.9로 계산됩니다.

## 사진
`assets/photos/`에 아래 이름으로 넣으면 자동으로 교체됩니다.
현재 `pool1.jpg`, `pool2.jpg`, `lobby.jpg`, `shuttle.jpg`가 들어 있습니다. 같은 이름으로 덮어쓰면 교체되고, 사진을 추가하려면 `index.html`의 갤러리에 한 줄 추가합니다.

## 대기 접수 · 상담 신청
- 휴대폰: 서식에 맞춰 작성된 문자가 `info.sms` 번호로 자동 입력됩니다.
- PC: QR 코드가 나오고, 휴대폰으로 찍으면 같은 문자가 작성됩니다.
- 시간표의 수업을 누르면 희망 시간(1·2·3순위)에 자동으로 추가됩니다.
